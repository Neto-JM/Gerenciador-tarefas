Detailed Description

Tarefa com prazo de vencimento definido.

Subclasse de Tarefa que representa atividades com data limite no formato DD/MM/AAAA. Sobrescreve estaVencida() para comparar o prazo com a data atual do sistema.

Verifica se a tarefa passou da data limite.

Compara o prazo armazenado com a data atual obtida do sistema. Tarefas já concluídas nunca são consideradas vencidas.

Returns
true se o prazo já passou e a tarefa ainda está pendente, false caso contrário.
