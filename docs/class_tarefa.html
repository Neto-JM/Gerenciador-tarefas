Detailed Description

Classe base que representa uma tarefa genérica.

Contém os atributos e comportamentos comuns a todos os tipos de tarefas do sistema. Deve ser herdada por TarefaSimples e TarefaComPrazo.

◆ estaVencida()

bool Tarefa::estaVencida ( ) const
virtual

Verifica se a tarefa está vencida (prazo anterior à data atual).

Método virtual que pode ser sobrescrito pelas subclasses. A implementação padrão analisa o campo prazo e compara com a data do sistema.

Returns
true se a tarefa está vencida e ainda pendente, false caso contrário.

Reimplemented in TarefaComPrazo, and TarefaSimples.
