Detailed Description

Registra e exibe o histórico de ações realizadas no sistema.

Mantém uma lista cronológica de descrições de ações (adição, edição, remoção, conclusão de tarefas, etc.) para fins de auditoria e rastreamento do uso do gerenciador.
