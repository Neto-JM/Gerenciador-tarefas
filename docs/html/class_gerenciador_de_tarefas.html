Detailed Description

Controlador principal do sistema de gerenciamento de tarefas.

Centraliza todas as operações sobre tarefas e categorias: criação, edição, remoção, listagem, filtragem, busca, persistência em arquivo e exibição de estatísticas e histórico.

Gerencia internamente a alocação dinâmica dos objetos Tarefa, liberando-os corretamente no destrutor.
