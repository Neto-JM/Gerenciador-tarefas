Detailed Description

Ponto de entrada do Gerenciador de Tarefas.

Implementa o menu interativo de linha de comando que permite ao usuário adicionar, editar, remover, listar, filtrar e buscar tarefas, além de gerenciar categorias, visualizar estatísticas, histórico e persistir os dados.
